Permissions & Special Bits Quick Reference 🔒

Permission Bit Numeric / Octal Symbolic Effect & Example
Read / Write / Exec 755 -rwxr-xr-x Owner has full rights (7); group & others read/execute (5). Standard scripts.
Read / Write Only 644 -rw-r--r-- Owner read/write (6); group & others read only (4). Standard documents.
SUID (Set User ID) 4000 -rwsr-xr-x Runs binary with rights of file OWNER (e.g. /usr/bin/passwd runs as root).
SGID (Set Group ID) 2000 drwxrwsr-x On directories: new files inherit parent directory's group for collaboration.
Sticky Bit 1000 drwxrwxrwt On shared folders: only file owner can delete/rename files (e.g. /tmp).

⚡ 60-Second Final Linux Master Exam Blitz & Golden Rules

Memorize these golden facts before any Linux interview or certification exam!

⚠️ Pete's 5 Golden Linux Safety Rules:

  • 1. No Trash Can in Terminal: rm deletes permanently with zero undo. Check your location with pwd!
  • 2. Preview Wildcards: Before typing rm *.tmp, test what will match by running ls *.tmp.
  • 3. Overwrite (>) vs Append (>>): > wipes destination completely; >> safely adds to bottom.
  • 4. Edit Sudoers with Visudo: Never edit /etc/sudoers with nano or vim directly; visudo prevents syntax lockouts!
  • 5. Respect Root Privileges: UID 0 can delete critical files instantly. Use sudo only when needed.
Origins: UNIX (1969 Bell Labs) ➔ GNU (1983 Richard Stallman) ➔ Linux Kernel (1991 Linus Torvalds).
Distro Families: Debian (.deb/APT), Ubuntu (LTS 5yr), Fedora (RPM/DNF modern), RHEL (10yr enterprise), Arch (Pacman rolling).
Navigation & Files: pwd (where you are), cd .. (up 1), ls -la (all dotfiles), touch (empty/time), file (magic bytes).
Text-Fu Streams: stdin (0), stdout (1), stderr (2). Pipes (|) connect stdout of left to stdin of right. tail -f follows logs live.
Search & Clean: grep -i (ignore case), grep -v (invert), sort -n (numeric), uniq -c (count adjacent duplicates).
Vim & Regex: Vim is modal (Normal vs Insert). :wq saves & quits; :q! force quits. ^ starts line, $ ends line.
Users & Databases: UID 0 is root. /etc/passwd (7 fields), /etc/shadow (encrypted hashes), /etc/group.
Permissions: Read=4, Write=2, Execute=1. 755 (scripts), 644 (docs). SUID runs as owner; Sticky (+t) protects /tmp.
Processes & Packages: ps aux, top, kill -15 (clean), kill -9 (force). apt / dnf resolve dependencies. tar -czvf / tar -xzvf.
